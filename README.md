# 💜 LuluhGo

**Compartilhe. Conecte. Go!**

LuluhGo é um aplicativo para Windows criado para compartilhar sua tela ou uma janela específica em tempo real pela internet, com suporte a áudio do aplicativo selecionado.

---

## ✨ Recursos

- 🖥️ Compartilhamento de tela em tempo real
- 🪟 Compartilhamento de uma janela específica
- 🔊 Áudio exclusivo do aplicativo selecionado
- 🔗 Criação automática de salas
- 📋 Link de convite para espectadores
- 🌐 Quem recebe o link pode assistir pelo navegador
- 📺 Qualidade 720p e 1080p
- 🎞️ Opções de 30 FPS e 60 FPS
- ⛶ Modo tela cheia
- 🔇 Controle de áudio para quem está assistindo

---
