# 💜 LuluhGo

**Compartilhe. Conecte. Go!**

LuluhGo é um aplicativo para Windows desenvolvido para facilitar o compartilhamento de tela em tempo real pela internet.

Com ele, você pode criar uma sala, compartilhar sua tela ou uma janela específica e enviar o link para outra pessoa assistir diretamente pelo navegador.

---

## ✨ Recursos

- 🖥️ Compartilhamento de tela em tempo real
- 🪟 Compartilhamento de uma janela específica
- 🔊 Áudio do aplicativo selecionado
- 🎧 Evita transmitir o áudio de outros aplicativos quando uma janela compatível é selecionada
- 🔗 Criação automática de salas
- 📋 Link de convite para espectadores
- 🌐 Espectadores podem assistir pelo navegador
- 📺 Opções de 720p e 1080p
- 🎞️ Opções de 30 FPS e 60 FPS
- ⛶ Modo tela cheia
- 🔇 Controle de áudio para quem está assistindo

---

## 📥 Como instalar

1. Baixe o arquivo:

   `LuluhGo Setup 1.0.0.exe`

2. Execute o instalador.

3. Conclua a instalação.

4. Abra o **LuluhGo**.

> O LuluhGo ainda não possui assinatura digital de distribuição. Por isso, o Windows pode identificar o desenvolvedor como não verificado. Instale somente uma cópia recebida de uma fonte em que você confia.

---

## 🚀 Como transmitir

1. Abra o **LuluhGo**.

2. Aguarde aparecer:

   `🟢 Conectado. Crie uma sala para começar.`

3. Clique em **Criar sala**.

4. Clique em **Compartilhar tela**.

5. Escolha a tela ou aplicativo que deseja compartilhar.

6. Configure a qualidade e o FPS.

7. Para compartilhar o som de um aplicativo específico, deixe:

   `☑ Áudio do aplicativo`

   ativado e selecione uma **janela de aplicativo**.

8. Copie o link da sala.

9. Envie o link para a pessoa que deseja assistir.

---

## 👀 Como assistir

Quem recebe o link não precisa instalar o LuluhGo apenas para assistir.

1. Abra o link recebido no navegador.
2. Aguarde a transmissão aparecer.
3. Para ouvir o áudio, clique em **🔊 Som ligado**.
4. Use **Tela cheia** se desejar.

---

## 🔊 Áudio por aplicativo

O LuluhGo possui um sistema próprio de captura de áudio para Windows.

Ao selecionar uma janela de aplicativo com a opção **Áudio do aplicativo** ativada, o LuluhGo tenta transmitir o áudio relacionado ao aplicativo selecionado em vez de simplesmente transmitir todo o áudio do computador.

Exemplo:

**Compartilhando Spotify:**

- 🎵 Spotify → transmitido
- 🔔 Outros sons do computador → não devem fazer parte da transmissão

Para esse recurso, escolha uma **janela de aplicativo**, e não a tela inteira.

---

## 🔄 Outra pessoa pode transmitir para mim?

Sim.

Se a outra pessoa instalar o **LuluhGo**, ela também pode:

1. Abrir o programa.
2. Criar uma sala.
3. Compartilhar a tela.
4. Copiar o link.
5. Enviar o link para você.

Você poderá abrir o link e assistir à transmissão dela.

## ⚠️ Versão atual

**Versão:** 1.0.0  
**Plataforma do aplicativo:** Windows 64 bits

O LuluhGo está em desenvolvimento. Esta versão deve ser considerada uma versão inicial de testes.

Algumas funcionalidades planejadas para versões futuras incluem salas com mais participantes, melhorias na experiência de transmissão e novos recursos de comunicação.

## 🛠️ Tecnologias utilizadas

O projeto utiliza tecnologias como:

- Electron
- Node.js
- Express
- Socket.IO
- WebRTC
- Web Audio
- HTML, CSS e JavaScript
- C++
- Windows WASAPI

O módulo nativo **LuluhGoAudio** é responsável pela captura de áudio utilizada pelo aplicativo no Windows.
